# Medipol · لوحة تحليلات Bitrix

تطبيق ويب لتحليلات بيانات Bitrix CRM المخزّنة في Supabase (جدولا `bitrix_deals` و
`bitrix_activities`). يحتوي شاشة تسجيل دخول (Supabase Auth) ولوحة تحكم فيها شارات
KPI ورسوم بيانية تفاعلية وفلاتر.

## المتطلبات
- Node.js 18+ (يفضّل 20+)

## التشغيل محليًا
```bash
npm install
npm run dev
```
سيفتح على http://localhost:5173

## الإعداد لمرة واحدة (مطلوب)

### 1) صلاحيات القراءة على قاعدة البيانات
جدول `bitrix_deals` مغلق حاليًا حتى على المستخدمين المسجّلين. افتح
**Supabase Studio → SQL Editor** ونفّذ محتوى ملف [`setup.sql`](./setup.sql).
هذا يسمح لأي مستخدم مسجّل دخوله بقراءة الجدولين (قراءة فقط) ويبقي الوصول
مغلقًا أمام الزوار.

### 2) حساب تسجيل الدخول
أنشئ مستخدمًا في **Supabase Studio → Authentication → Users → Add user**
(فعّل *Auto Confirm User*)، ثم استخدم بريده وكلمة مروره للدخول.

## الإعدادات (ملف `.env.local`)
```
VITE_SUPABASE_URL=https://supabase-automation.medipol.edu.tr
VITE_SUPABASE_ANON_KEY=<anon key>
```
> ⚠️ لا تضع مفتاح `service_role` هنا أبدًا — هو مفتاح إداري يتخطى كل الحماية
> ولا يصلح للاستخدام في الواجهة الأمامية.

## البناء للنشر
```bash
npm run build      # يولّد مجلد dist/
npm run preview    # لمعاينة نسخة الإنتاج محليًا
```
يمكن نشر مجلد `dist/` على Vercel أو Netlify أو أي استضافة ملفات ثابتة.

## ما الذي تعرضه اللوحة
- **شارات KPI:** إجمالي الليدز، قيد المعالجة، مقبول، مرفوض، معدل التحويل،
  ليدز آخر 30 يومًا، تواصل واتساب، عدد الدول، إجمالي الأنشطة، نسبة الأنشطة المكتملة.
- **رسوم الليدز:** عبر الزمن، حسب المرحلة، المصدر، الدولة، الجنسية، الموظف المسؤول،
  الكلية، المستوى، فترة التقديم، المنطقة، أسباب الرفض، الحملات الإعلانية.
- **رسوم الأنشطة:** عبر الزمن، حسب النوع/المصدر، الاتجاه (وارد/صادر)، المسؤول.
- **فلاتر:** نطاق تاريخ، المرحلة، الدولة، المستوى، فترة التقديم.

## هيكل المشروع
```
src/
  supabase.js          عميل Supabase
  App.jsx              بوابة المصادقة (Login / Dashboard)
  components/
    Login.jsx          شاشة تسجيل الدخول
    Dashboard.jsx      الحاوية الرئيسية (تحميل + فلاتر + تجميع)
    Kpi.jsx            شارات KPI
    Filters.jsx        شريط الفلاتر
    Charts.jsx         مكوّنات الرسوم (Recharts)
  lib/
    data.js            جلب البيانات مع الترقيم (pagination)
    aggregations.js    حسابات التحليلات (client-side)
    labels.js          تسميات القيم المرمّزة + الألوان
```
